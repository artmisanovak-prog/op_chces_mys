API kontrakt pro inference endpoint

Požadavek je POST JSON. Server musí povolit CORS z domény této stránky.

{ "task_id": "task_001", "task": {"train": [], "test": [{"input": [[0,1]]}]}, "include_train": true, "prompt": "Solve the ARC task and return a prediction grid." }

Očekávaná odpověď pro jednu testovací mřížku: {"prediction":[[0,1]]}. Pro více testů: {"predictions":[{"output":[[0,1]]}]}. Chat endpoint přijímá {"message":"...","model":"Model A"} a vrací {"reply":"..."}.

Bezpečnost: pokud bude stránka veřejná, nepoužívej v ní tajné tokeny. Vytvoř malý backend/proxy, který je drží server-side. Endpoint musí být tvoje vlastní služba nebo služba, jejíž pravidla dovolují tento způsob použití.
