# CASMI: inventura dat

## K čemu slouží
Skript pro zjištění, jaké datové soubory jsou dostupné a jak jsou strukturované. Má pomoci před experimentem zjistit, zda vstupy skutečně odpovídají očekávání.

## Jak ho vyzkoušet
Spusť inventuru nad kopií datového adresáře. Projdi výstup a ověř, zda počty souborů, přípony a očekávaná pole odpovídají zdroji dat.

## Silné stránky
- Odhalí chybějící soubory a odchylky struktury dříve, než se spustí model.
- Odděluje kontrolu vstupních dat od vyhodnocení metody.

## Limity
- Inventura sama nepotvrzuje správnost chemických anotací.
- Počet souborů není metrika vědecké kvality ani přesnosti modelu.
