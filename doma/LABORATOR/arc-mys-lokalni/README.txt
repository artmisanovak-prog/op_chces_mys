MYŠ + ARC-AGI-2: první prototyp

Myš není AI. Tento prototyp je lokální repozitář úloh a evidenčních záznamů.
Umí načíst ARC JSON, zobrazit ukázkové mřížky a ukládat záznamy vlastností,
vztahů a nejistot do samostatných JSON souborů.

Spuštění:
- Windows: spusť start_windows.bat
- Mac/Linux: python3 app.py
Pak otevři http://127.0.0.1:8000

Je potřeba Python 3.10+, bez dalších knihoven.
Do složky data můžeš přidat JSON soubory z oficiálního repozitáře ARC-AGI-2.

Toto je základ, nikoli hotový řešič ARC ani soutěžní submission.
Neznámé není totéž co nula. Pokud zdroj neříká, proč hodnota chybí,
aplikace nesmí důvod domýšlet.
