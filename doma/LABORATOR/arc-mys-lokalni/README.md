# Lokální ARC evidence

## K čemu slouží
Malá Python aplikace pro lokální práci s ARC záznamy a ukázkovými JSON daty. Je určená pro počítač s Pythonem, nikoli pro přímé spuštění na GitHub Pages.

## Jak ji vyzkoušet
Přečti `README.txt` a `data/README.md`, zkontroluj ukázkový soubor a spusť `start_windows.bat` na Windows nebo aplikaci ručně příkazem uvedeným v dokumentaci. Nejprve používej pouze demo data.

## Silné stránky
- Data lze zpracovávat lokálně.
- Jednoduchá aplikace může být užitečná pro kontrolu workflow před stavbou složitějšího systému.

## Otevřené otázky
- Provozní postup je orientovaný na Windows; jiný systém může vyžadovat ruční spuštění.
- Ukázková data nejsou oficiální benchmark ani měření výkonu.
- Je nutné ověřit, jak aplikace ukládá záznamy a zda podporuje více testovacích vstupů.
