# ARC Lab

## K čemu slouží
Rozhraní pro prohlížení a organizaci experimentů nad ARC úlohami. Je potřeba rozlišovat mezi vizualizací dat, ručním zkoušením pravidel, spouštěním modelu a oficiálním soutěžním agentem. Samotná HTML stránka není automaticky žádnou z posledních dvou věcí.

## Jak ho vyzkoušet
Otevři `index.html`, načti ukázkovou úlohu a ověř, jak reprezentuje mřížku, vstup, výstup a pokusy. Pak zjisti, zda řešení ukládá, exportuje a dokáže znovu načíst.

## Silné stránky
- Vizuální přístup usnadňuje ruční kontrolu úloh.
- Může sloužit jako prototyp uživatelského rozhraní pro experimenty.

## Otevřené otázky
- Které datové formáty skutečně podporuje.
- Zda umí pracovat s více testovacími vstupy a více pokusy na jednu úlohu.
- Není to totéž co interaktivní ARC-AGI-3 agent.
- Demo data ani vizuální výstup nejsou důkazem přesnosti.
