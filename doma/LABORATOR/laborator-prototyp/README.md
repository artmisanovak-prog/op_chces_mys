# Laboratorní prototyp

## K čemu slouží
Pracovní prostor pro čtení pohádek a prohlížení ilustrací a pro zaznamenávání pozorování, interpretací, vztahů, změn, přenosů a limitů. Uživatel může pracovat s materiálem jako s podnětem a zapsat vlastní hypotézu, aniž by musel okamžitě rozhodnout, že je správná.

## Jak ho vyzkoušet
Otevři `index.html`. Vyber příběh, odděl popis toho, co v něm skutečně je, od navrženého vztahu. Potom změň jednu podmínku, popiš novou konfiguraci a zapiš, co se do jiného kontextu přenáší a co nikoli. Nakonec záznam exportuj.

## Silné stránky
- Zachycuje průběh uvažování, nejen finální interpretaci.
- Umožňuje evidovat i selhání a hranice platnosti nápadu.
- Nevyžaduje API ani model; může sloužit jako ruční kvalitativní nástroj.

## Otevřené otázky
- Záznamy nejsou samy o sobě objektivní měření kognice.
- Různí uživatelé mohou stejná pole chápat různě; pro výzkum by bylo třeba zavést anotovací protokol.
- Je nutné ověřit, zda se lokální záznamy bezpečně exportují a obnovují.
- Pokud stránka načítá soubory přes fetch, otevření přímo z disku může narazit na omezení prohlížeče.

## Kdy se hodí
Pro ruční průzkum vztahů v textu a obrazu, tvorbu hypotéz a přípravu materiálu pro pozdější experiment.
