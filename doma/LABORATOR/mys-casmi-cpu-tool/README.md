# MYŠ CASMI CPU Tool: starší varianta

## K čemu slouží
Samostatný starší prototyp pro práci s CASMI/MS-MS daty na CPU. Zachovává se odděleně, aby bylo možné porovnat jeho vstupní formát, algoritmus a výstup s pozdějším CASMI baseline.

## Co porovnat
- Jak načítá spektra a jak normalizuje data.
- Jak definuje podobnost a řadí kandidáty.
- Jaké metriky nebo výstupy ukládá.
- Zda novější varianta mění algoritmus, nebo pouze organizaci kódu.

## Limity
Nepovažuj starší a novější implementaci za zaměnitelné bez přímého testu. Samotné spuštění na několika příkladech nedokazuje obecnou přesnost.
