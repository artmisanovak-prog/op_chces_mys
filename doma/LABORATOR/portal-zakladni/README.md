# Základní portál

## K čemu slouží
Lehký rozcestník pro lokální data, projekty a samostatné nástroje. Jeho úkolem je zpřístupnit pracovní plochy, ne stát se centrální databází nebo řídit všechny ostatní aplikace.

## Jak ho vyzkoušet
Otevři `index.html`, projdi odkazy na jednotlivé nástroje a ověř, které cesty skutečně existují. Vyzkoušej práci s lokálním souborem a exportem, pokud je daná funkce implementovaná.

## Silné stránky
- Nízká složitost a jednoduché oddělení nástrojů.
- Lze jej hostovat jako statické HTML.
- Uživatel může nástroje otevírat samostatně bez backendu.

## Otevřené otázky
- Odkaz na nástroj není totéž jako jeho integrace.
- Formáty souborů, import a export musí být popsány u každého nástroje zvlášť.
- Pokud se data ukládají pouze v prohlížeči, portál je automaticky nesdílí mezi zařízeními.
