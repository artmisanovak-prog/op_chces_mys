Dokumentace

Struktura, datový tok a skutečné limity prototypu.

1. Soubory

  • index.html rozcestník.
  • generator.html vybere kartu, zobrazí ilustraci a odkaz na pohádku, skládá prompt a exportuje kartu JSON.
  • laborator.html zapisuje experimenty, větví je a exportuje/importuje záznamy.
  • porovnani.html drží společné zadání, dvě varianty, výstupy a kritéria.
  • manifest.json strojově čitelný přehled nástrojů a omezení.

2. Relativní cesty

ROOM je v doma/room/. Obrázky se načítají z ../chces_mys/ilustrace/ a pohádky se odkazují do ../chces_mys/kriva_pohadka/. Nepřidávej na začátek lomítko, jinak by cesta mířila od kořene webu, ne od aktuální složky.

Názvy souborů musí odpovídat názvům v původních složkách. Například Panda používá ilustraci panda.jpg a pohádku panda.txt.

3. Karta jako API

Karta je datový balíček, ne síťové API. Může obsahovat identifikátor, zvíře, úhel, generativní větu, odkaz na ilustraci, odkaz na pohádku a cíl generování. Nástroje z něj vytvářejí prompt a JSON export. Při přidání dalšího nástroje může znovu použít stejný formát.

4. URL jako stav

Generátor kóduje hodnoty formuláře do fragmentu za #. Fragment se neposílá serveru. Je vhodný pro sdílení stavu, ale URL může být dlouhá a každý, kdo ji získá, může přečíst zakódované hodnoty. Nevkládej do ní hesla, klíče ani citlivé údaje. V laboratoři se do fragmentu ukládá pouze ID a vlastní záznam zůstává v místním úložišti.

5. Paměť a přenos

localStorage je vázán na prohlížeč a origin. Data se nepřenášejí automaticky mezi telefonem, počítačem, souborem otevřeným přes file:// a GitHub Pages. Použij export/import JSON a uchovávej zálohy.

6. Modely a API

Verze 1.0 model přímo nevolá. Prompt se kopíruje do libovolného rozhraní a výstup se vloží zpět. Tím lze porovnávat různé modely bez registrace klíčů v aplikaci. Nedávej API klíč do veřejného HTML: kdokoli by jej mohl získat. Pro automatické volání API by bylo potřeba bezpečné zprostředkování nebo lokální pomocná služba.

7. Experimentální disciplína

Před testem stanov kritéria. Pokud porovnáváš modely, zachovej stejné zadání a zaznamenej verzi modelu, instrukci a další rozdíly. Odděluj pozorování od hypotézy. Výstup označený jako „funkční prototyp“ by měl mít popsaný a opakovatelný test.

8. MYS WORKSHOP

workshop.html přijímá pracovní zadání, cílový typ výstupu, publikum a omezení. Automaticky porovnává zadání s tematickými značkami a mechanismy dostupných pohádek. Vybrané celé texty vkládá přímo do promptu, aby je model skutečně dostal jako kontext a nemusel si je načítat přes odkaz.

Režim konverzačního modelu připraví prompt ke kopírování. Experimentální režim API volá endpoint ve formátu chat completions; vyžaduje API klíč zadaný pouze do aktuální relace a povolené CORS. Veřejný statický web neumí chránit tajemství před uživatelem zařízení. Pro stabilní produkční API integraci je potřeba důvěryhodný serverový proxy.

Automatický výběr je v této verzi založen na tematických značkách a shodě slov s textem zadání, nikoli na embeddingovém vyhledávání nebo sémantickém modelu. Výběr proto můžeš ručně změnit. Nedostupné texty nejsou vydávány za načtené.
